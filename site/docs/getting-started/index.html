Try a change to a reading list in your browser. Two saved articles are already waiting in the guided example. No account or installation is needed. Installation instructions will follow the Denton package release.

Open the sample

Follow Try a change on the homepage. The editor starts with Save changes. Your task is to add a way to remove an article while keeping the rest of the list intact.

Ask for one scoped change

text
Add a confirmed Remove item action to the editor.
Preserve the existing list and edit flow.
Inspect the semantic graph, propose the change, and wait for my approval.

Select Review the change. Open the graph change to see the one editor action and the existing operation it calls. Keep the original to leave the editor unchanged, or approve to add the action.

See the approved result

Approval adds the button. Select Remove item to open its confirmation. Cancel or press Escape to keep the article. Confirm to remove it from the temporary sample, then use Reset example to restore both articles and the original editor.

Continue with Semantic Graph or use Troubleshooting if a step fails. Source-checkout contributors retain their separate documentation-sample guide.
